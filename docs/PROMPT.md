# 提示词与回复协议

想知道「为什么 TA 会这样回」、或者想自己调，看这篇。

## 一次手机回复长什么样

### 系统提示（system）

```text
你正在扮演「夏之」，在一个手机聊天软件里和「林晚」发消息。

【人物设定】
二十六岁，在旧城开一间修表铺。话不多，习惯把关心藏在小事里……
性格：安静、克制、心软，嘴上不肯承认。

【你和 TA 的关系 / 备注】
认识很多年的旧朋友。他开修表铺，话少，习惯把关心放在小事里。

【最近发生的事（只作背景，不要复述）】
夏之：外面下雪了。你要是还没回，就先去我店里坐一会儿。
我：在路上了，雪有点大。

【说话方式】
你在用手机聊天软件回复对方。像真的发消息：口语、简短、有停顿和语气词……

【手机消息格式】一行就是一条消息。可以直接写文字，也可以发这些：
[图片] 画面里有什么
[语音] 你想说的话
[红包 ¥金额] 祝福语
[转账 ¥金额] 备注
[位置] 地点名
[表情] 😊
一轮可以发 1 到 5 条，按这个人此刻的心情决定；不要每轮都一样多。

只输出消息本身。不要写旁白、动作、心理描写、时间戳，不要解释。
```

### 用户提示（user）

```text
这是你们最近的聊天记录：
我：在路上了，雪有点大。
夏之：门口给你留了灯。慢点走，别摔。
我：我到了

我刚刚发完最后一条，等你的回复。
现在轮到你发消息。
```

### 模型应该回

```text
[图片] 窗台上堆了薄薄一层雪
到了就好。
茶还热着。
```

## 解析规则

- 一行 = 一条消息
- 行首的 `-`、`*`、引号会被去掉
- `[图片]/【图片】`、`[语音]`、`[红包 ¥8.88]`、`[转账 ¥52]`、`[位置]`、`[表情]` 都会变成对应的气泡
- 整行只有一个 / 几个 emoji 时，当作表情消息
- 群聊里用 `名字：内容` 开头；没写名字的续行算上一条的说话人
- 只输出 `[不发]` 表示这次不发言（主动来信时用）
- 最多取 7 条（主动来信 4 条），每条超过 900 字会被截断

## 人物提取协议

通讯录第一次「找人物」时，会把卡名、简介、性格、场景、示例对话发过去，要求：

```json
{"people":[{"name":"名字","role":"身份","relation":"和用户的关系","desc":"一两句人设","style":"说话方式"}]}
```

拿到之后存在当前聊天的 §world.cast§ 里。之后聊天时，系统提示里的「你是谁」用的是这个人的 desc / style / relation，而不是整张卡的描述。

## App 内容协议

每个 App 有自己的 JSON schema（§src/feed.js§）：

- 抖音：§{"videos":[{"author","title","desc","tags","likes","comments","shares","music","mood"}]}§
- 微博：§{"hot":[{"title","heat","tag"}],"posts":[{"author","time","text","topic","likes","comments","reposts"}]}§
- 小红书：§{"notes":[{"author","title","text","likes","collects","mood"}]}§
- B 站：§{"videos":[{"author","title","tag","views","danmaku","duration","mood"}]}§

§mood§ 决定封面的配色（warm / cold / night / neon / street）。解析失败或生成超时，会回落到内置的兜底内容。

## 朋友圈协议

要求模型只输出 JSON：

```json
{
  "posts": [
    {
      "author": "沈知微",
      "text": "今天有人站在诗集那排前哭了十分钟……",
      "likes": ["夏之", "阿澈"],
      "comments": [{ "by": "夏之", "text": "你每次都这样。" }]
    }
  ]
}
```

插件会抠出第一段 JSON 解析；如果模型不听话，会退化成按 `作者：内容` 逐行读。

作者会被限制在「当前会话里的人 + 当前角色 + 酒馆前 10 个角色」范围内，防止编出不存在的人。

## 主动来信协议

系统提示会换成一段「你们没在聊天，判断 TA 此刻会不会主动发消息」，并要求：

> 想发就按格式发 1 到 3 条；不想发就只输出 `[不发]`。

另有冷却时间（默认 120 秒）和每小时上限（默认 4 次），防止刷屏和烧钱。
