# 使用说明

这篇讲**怎么用**；提示词协议在 [PROMPT.md](PROMPT.md)，整体介绍在 [README](../README.md)。

## 打开与收起

| 方式 | 说明 |
| --- | --- |
| 右下角悬浮球 | 桌面上一直有；手机会自动变成全屏 |
| 魔杖菜单「小手机」 | 输入框左边的魔法棒菜单 |
| 扩展设置 | 「幻镜手机」面板里的「打开小手机」 |
| `Alt + P` | 键盘开关 |

窗口操作（桌面端）：

- 按住顶部状态栏拖动
- 双击状态栏：全屏 / 窗口
- 全屏时按 `Esc` 或点空白处退出
- 点手机底部那条横线：回主屏

手机上打开酒馆时，会自动使用全屏布局，不需要拖动。

## 主屏

- 顶部大时钟、日期和天气（点天气那一行直接进天气 App）
- 「最近的手机消息」：点一下直接进那个会话
- 八个应用：消息、朋友圈、通讯录、相册、备忘录、钱包、天气、设置
- 底部 Dock 放最常用的四个；未读数量显示在图标右上角
- 收到消息时：顶部会滑下来信横幅，灵动岛展开；手机收起来时悬浮球会亮红点并轻轻晃一下

## 消息

### 开始一段对话

通讯录 → 让手机先从卡里找出人物 → 点一个人 → 发第一句。第一次进来可以点建议的句子。

### 输入框

- `Enter` 发送，`Shift + Enter` 换行（手机上用发送按钮）
- 左边「＋」收起 / 展开快捷功能
- 快捷功能：图片、语音、红包、转账、位置、表情

### 收到的消息类型

| 类型 | 怎么来的 | 手机上怎么显示 |
| --- | --- | --- |
| 文字 | 最常见 | 气泡 |
| 语音 | 模型写 `[语音] …` | 声波气泡，点一下显示文字 |
| 图片 | 模型写 `[图片] …` | 文字生成的「拍立得」色块 + 说明 |
| 红包 | 模型写 `[红包 ¥8.88] 祝福` | 橙色卡片，点「领取」后变灰 |
| 转账 | 模型写 `[转账 ¥52] 备注` | 金额卡片 |
| 位置 | 模型写 `[位置] 旧城·修表铺` | 小地图卡片 |
| 表情 | 单独一个 emoji，或 `[表情] 😊` | 大号 emoji |

你自己发的图片是**真图片**：选本地照片，压缩后存在浏览器里，聊天数据里只留一个 id。

### 会话菜单（右上角 ···）

- **带进剧情** — 把最近几条手机对话写进下一次正文的提示里
- **让 TA 回一条** — 不等你说话，直接让对方接一句
- **关系备注** — 写「认识很多年的旧朋友，话少，习惯把关心藏在细节里」这种；会进入每次手机回复的提示词
- **清空记录** — 只清这段会话

长按会话：置顶 / 免打扰 / 删除。长按一条消息：复制 / 带进剧情 / 删除。

## 朋友圈

- 右上角 **✦** 换一批：让模型根据最近剧情生成 3 条新动态
- 右上角 **＋** 发一条：发完好友会来点赞、评论
- 点「赞」：自己点赞 / 取消
- 「评论」：输入后发出去，被评论的人会回你

## 群聊

- 通讯录右上角的**群聊按钮**：选两到四个人，起个群名，就能建群
- 群里模型会按 `名字：内容` 分行，几个人可以抢着说话，也可以互相吐槽
- 群里每个人都会用自己的角色卡设定接话

## 通讯录：这个世界里的人

手机聊天的对象是**角色卡里的人**，不是角色卡本身。

- 打开一张卡后，点世界卡片上的「找人物」，模型会从卡里抽出 4–8 个人，写上身份、关系、人设和说话方式（一次模型请求）
- 点人开始聊天；聊天提示词用的是这个人的设定 + 你们的关系 + 卡里的世界设定
- 右上角 **＋**：手动添加一个人（名字 / 身份 / 关系 / 人设 / 说话方式）
- 长按一个人：编辑 / 从通讯录移除
- 换卡或换聊天后，名单不会跟着走；需要重新找一次
- 群聊：选人建群，群里每个人用自己的设定接话

## 应用商店

- 主屏上的 **应用商店**：获取 / 打开 / 移除
- 装上以后，图标会出现在主屏（主屏可以往下滑）
- 现在上架：抖音 / TikTok、微博、小红书、哔哩哔哩
- 每个 App 第一次打开会先用兜底内容，再在后台让模型按「世界 + 人物 + 最近剧情」生成；右上角刷新会重新生成一次
- 界面是照着真实 App 重画的：抖音只留刷视频、点赞、评论、分享，没有团购 / 同城；微博有热搜和动态；小红书是双列笔记；B 站是双列视频卡片

## 相册

- **剧情画面**：自动扫描最近 160 条正文里出现的图片（`<img>` 和 Markdown 图片），倒序排列
- **收藏**：你点开一张图后按 ☆ 收藏的图片
- 点图片放大，可以收藏 / 取消收藏
- 收藏只存图片地址；跨设备不一定能打开

## 备忘录

- 右上角 **＋** 新建，写文字，可以置顶
- 点已有的便签编辑；右下角垃圾桶删除
- 右上角 **✦**「记下今天」：让当前角色用第一人称写一篇 150–350 字的日记，写最近 12 条正文里发生的事

日记是 AI 写的，不满意就删掉再点一次。

## 钱包

- 余额 = 收到的转账 + 已领取的红包 − 你发出去的红包 / 转账
- 明细点进去就是对应的聊天

金额是虚构的，不涉及真实支付。

## 天气

- 城市默认「此间」，点标题可以改
- 天气由日期 + 城市名稳定生成：同一天反复打开不会变
- 如果最近 3 条正文里出现「雪 / 雨 / 雷 / 晴 / 阴」，天气会跟着变，并在底部标一句「今天的天气跟着最近的剧情走」
- 温度、湿度、风力、空气、日出日落、未来 12 小时、未来 5 天都是算出来的，不联网

## 设置

### 外观

| 项 | 说明 |
| --- | --- |
| 主题 | 跟随系统 / 浅色 / 深色 |
| 强调色 | 暖阳、蔷薇、薄荷、晴空、暮紫、墨色 |
| 壁纸 | 极光、暮色、樱雪、深林、纸感，或上传自己的照片 |
| 玻璃质感 | 0–140%，影响毛玻璃模糊强度 |
| 个性签名 | 显示在朋友圈名片上 |

### 手机

| 项 | 说明 |
| --- | --- |
| 窗口大小 | 桌面端整体缩放 70%–135% |
| 灵动岛 | 收到消息 / 正在输入时展开 |
| 振动反馈 | 手机上发送、领红包时轻轻震一下（需要浏览器支持） |

### AI

| 项 | 说明 |
| --- | --- |
| 回复长度 | 一次最多生成多少 tokens；调小更短更省钱 |
| 口吻规则 | 每次手机回复都会带上的「说话方式」；留空恢复默认 |
| 剧情后主动来信 | 正文回复后多一次请求，让角色决定要不要发消息；默认关闭 |
| 最短间隔 | 两次主动来信之间至少隔多久（默认 120 秒） |
| 把手机消息带进正文 | 每次生成前注入一小段手机摘要 |
| 注入深度 | 0 最靠近正文末尾，数字越大越靠前 |
| 看看现在注入的内容 | 预览当前会注入什么，排版是否正常 |

### 数据

- **导出**：把这部手机的聊天、朋友圈、备忘、收藏存成 JSON
- **导入**：覆盖当前聊天的手机数据
- **清空**：只清当前聊天

导出的 JSON 不含主题设置，换设备时外观需要重新调。

## 推荐玩法

1. **先有剧情，再有手机**：先在酒馆里正常聊 3–5 轮，让手机知道你们在哪、发生了什么。
2. **手机里推进关系**：用朋友圈看角色「背着你说的话」。
3. **把手机带回去**：聊到关键处点「带进剧情」，让正文接上；或者开着「注入」，让模型自然提到手机上的事。
4. **偶尔开主动来信**：深夜、吵架之后、刚分开，角色主动找你的那一刻最值回票价。介意费用就临时打开，用完关掉。

## 故障排查

**没有手机图标**
刷新页面；确认扩展已启用；打开控制台看有没有 `[幻镜手机]` 的报错。

**点了发送没回复**
- 看右下角 toast 的报错
- 确认酒馆能正常聊天（同一个模型）
- 酒馆版本 ≥ 1.13.2（`getContext().generateRaw`）

**回复变成一大段、没有气泡感**
模型没有按格式分行。可以：
- 把回复长度调小
- 在口吻规则里加一句「一行就是一条消息」
- 换一个更听话的模型

**「找人物」失败或者找不到人**
- 模型没有按 JSON 回：再点一次，或者换一个更听话的模型
- 卡里几乎没有人物描述：手动添加几个人
- 当前是群聊卡：先在酒馆里选一张单人卡

**App 里没有内容 / 内容很久没变**
- 第一次打开先显示兜底内容，几秒后才会换成模型生成的
- 点右上角刷新；一次刷新一次模型请求
- 生成失败会留在兜底内容上，并弹出提示

**图片 / 声音不显示**
角色发的图片本来就是占位色块；语音只有文字。你自己上传的照片如果换了浏览器就没了。

**数据会不会串聊天**
不会。所有数据都挂在当前聊天的 `chatMetadata` 上，和角色卡、世界书都不冲突。
