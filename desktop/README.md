# 幻镜手机 · 独立桌面版（骨架）

第 2 步：把手机 UI 从酒馆页面里搬出来，先跑**离线模式**。

## 跑起来

```powershell
cd desktop
npm install          # 只装 electron
npm start
```

窗口会打开手机界面（复用仓库里的 `preview/` 演示环境，内置 ST stub，所以不连酒馆也能用）。

## 现在具备

- 独立窗口（无边框菜单、全屏手机 UI）
- 关窗口 = **收进后台**，进程不退出；`Ctrl/Cmd + Shift + P` 唤出/收起
- 离线可用：夜约、记忆、浏览器、设置、Pixiv 风格图等不依赖酒馆的功能

## 还没有（第 3 步）

跟酒馆的桥接：当前角色卡 / 当前聊天 / chatMetadata / 消息流。
计划是酒馆里装一个极小的桥接插件，开本地 WebSocket 推送；桌面端连上后进入"联动模式"，没连上就是离线模式。

相关入口预留在 `main.js` 顶部注释与 `bridge.js`（待添加）。
